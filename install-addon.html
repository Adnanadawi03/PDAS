📧 Gmail Add-on

Install the PDAS add-on in Gmail to scan emails directly from your inbox.

1
Go to script.google.com and sign in with your Google account
2
Click New Project → rename it to PDAS Email Guard
3
Delete the default code, then click the button below to copy the PDAS add-on code
4
Paste the code into the editor. Then click the + next to Files → add a new file named appsscript (type: JSON) and paste the manifest code
5
Click Deploy → Test deployments → Install → Open Gmail and look for the PDAS icon in the right sidebar
6
Open any email → click the PDAS icon → Sign in with your PDAS email & password → done!
